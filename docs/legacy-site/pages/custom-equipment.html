Системы ориентации бутылки

Установка столиков с донным ориентатором на этикетировочное оборудование без функции ориентирования бутылки. Также, возможно установить систему ориентации бутылки по боковому выступу, или по визуальной метке на колпачке или других элементах дизайна.

Укладка акцизной марки

Блок устанавливается на выходном валу роторной этикетировочной машины. Предназначен для укладывания П-образной акцизной марки на горло бутылки. Оснащен подвижной передней и задней подушками

Столы формирователи

Стол для автоматического формирования слоя бутлей 3х4 для работы с автоматическим паллетизатором 

Головки для манипуляторов

Головка с пневматическими захватами для двенадцати бутлей установлена на автоматический паллетизатор. Головка позволяет надежно захватывать 12 наполненных бутлей для установки на паллету.

Системы ориентации по оптической метке

Поворотная платформа с двумя оптическими датчиками метки. Является частью системы ориентации бутылки на роторных машинах. Совершая повторяющиеся повороты сопровождает заходящие на карусель бутылки. Ориентация бутылки происходит при помощи поворотного столика за время сопровождения бутылки датчиком на платформе.

Конвейер для заворачивания блинчиков с начинкой

Двухрядный ленточный конвейер с системой ножевого разворота со стороны разгрузки. Для манипуляций с блинчиками по длине конвейера установлены универсальные точки крепления оснастки с возможностью легкого демонтажа для мойки. Задняя часть конвейера с холостыми звездочками выполнена откидной для ослабления конвейерной ленты при мойке.

Диспенсер для теста машины для производства блинов BALPE

Диспенсер выполняет функцию отсадки заготовок из жидкого теста на машинах по производству блинов. Отсадка происходит с вращением головки, что обеспечивает идеально круглую форму заготовки.

Перекрытие канала подачи теста в период перемещение головки на следующее место отсадки гарантирует отсутствие капель теста между блинами.
