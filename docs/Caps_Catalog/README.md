# Каталог пробок і кришок — з чого починати

**Чим ми тут займаємось.** Sofon робить форматні деталі для ліній розливу, і
робота з пробкою — окремий напрям усередині цього. Щоб про неї писати, треба
знати самі пробки: як влаштований кожен тип, чим тримається на пляшці, що
міняється на лінії при переході з одного на інший. Цей каталог — така база.
Джерело переліку — каталог AROL, 28 типів; далі він доповнювався тим, що назвав
власник.

## Чотири файли, і що в якому

| Файл | Що це | Коли відкривати |
|---|---|---|
| **`Пробки.md`** | усі позиції з готовими текстами для сайту, одним списком, зі станом кожної | коли треба взяти текст на сторінку або подивитись, що вже затверджено |
| **`Довідка.md`** | розуміння предмета. **Зверху — зведення фактів від власника**, далі галузева довідка по кожному типу з посиланнями на джерела | коли треба зрозуміти виріб або перевірити, звідки взявся факт |
| **`Джерела.md`** | робочі записки: що дали каталоги тари й виробників, де джерела суперечать одне одному | коли джерело виглядає сумнівним або треба українська ринкова назва |
| **`Caps_Catalog.md`** | ⚠ **архів.** Перша чернетка, з якої все починалось. Перекрита `Довідка.md`, **не редагується** | майже ніколи; там лежать типи, до яких ми не дійшли |

Плюс `images/` — картинки й [`СПИСОК-ФОТО.md`](images/СПИСОК-ФОТО.md), перелік
того, під що потрібні фотографії.

## Що треба знати, перш ніж щось тут писати

1. **Наші факти — тільки те, що сказав власник.** Усе інше в `Довідка.md` —
   галузева довідка з відкритих джерел: опора для розуміння, не наш факт.
   Зведення сказаного власником стоїть першим розділом `Довідка.md`.
2. **Чужих чисел на сторінку не носимо.** Ні десятих часток міліметра, ні
   каталожних розмірних рядів постачальників. Немає нашого числа — не пишемо
   числа.
3. **Не вигадувати класифікацій.** Каталог не ділиться на блоки, і заводити
   поділ не треба — це пряме рішення власника.
4. **Не описувати обладнання читача.** Читач — технолог або механік; його
   машину він знає краще. Пишемо про виріб і про нашу роботу.
5. **Припущення про поведінку деталі в тракті — не факт, а питання власнику.**
   За одну сесію чотири такі здогади виявились хибними поспіль.

## Що зараз відкрито

- **Межа між описом пробки й описом комплекту оснастки** — не вирішена,
  рішення за власником. Розгорнуто в `CLAUDE.md` репозиторію. Поки відкрито,
  рядки про подачу з каталогу не прибирати й нових не додавати.
- **Фотографії** — власник дає свої, перелік у `images/СПИСОК-ФОТО.md`.
- **Сторінки сайту по типах пробок ще не існує.** Каталог поки тільки текст.
