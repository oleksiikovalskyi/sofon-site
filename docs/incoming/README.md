# Inbox для нових текстових матеріалів

Сюди власник кладе сирі матеріали, які ще не розібрані: тексти, вигрузки,
шматки листування, надиктоване. Формат будь-який.

**Що з ними робиться.** Матеріал розбирається й розкладається по полотнах
копірайту — `docs/screws-canvas.md` (шнеки) і `docs/change-parts-canvas.md`
(форматні деталі). Порядок роботи описаний у `docs/PROMPT_enrich-canvases.md`.

**Файли звідси не видаляються після розбору** — вони лишаються як джерело, на
яке посилаються бирки в полотнах. Якщо в тексті полотна колись виникне сумнів
«звідки це взялось», відповідь має бути тут.
