# Техническое задание

## Создание иллюстрированного каталога типов пробок и крышек

### Цель

Создать подробный справочный каталог всех типов пробок и крышек,
упоминаемых в документе `Каталог_типов_пробок_и_крышек.md`.

## Исходный документ

Исходным перечнем обязательных позиций является файл
**Каталог_типов_пробок_и_крышек.md**. Все позиции должны быть
сохранены.

## Для каждой позиции необходимо собрать:

-   английское название;
-   русское название;
-   украинское название;
-   минимум одну качественную фотографию (лучше несколько);
-   материал крышки;
-   материал тары;
-   тип тары;
-   область применения;
-   способ укупоривания;


## Требования к фотографиям

Использовать изображения со свободной лицензией. Предпочтительные источники: -
производители крышек; - производители упаковки; - Wikimedia Commons; -
технические каталоги; - открытые источники.

Для каждого изображения указать источник и ссылку.

## Структура записи

``` markdown
## English Name (Русское название)(Украинское название)

![Фото](images/file.jpg)

### English name
### Русское название
### Украинское название
### Описание
### Материал
### Тип тары
### Продукция
### Ообласть применения;
### Способ укупоривания

```

## Формат результата

    Caps_Catalog/
    ├── Caps_Catalog.md
    ├── README.md
    └── images/

Итоговый каталог должен содержать все позиции из исходного файла и быть
пригодным как источник для наполнения сайта компании занимающейся оборудованием, которое работает с пробками и ее презентационных материалов
