# Каталог типов пробок и крышек AROL

## 1. Вода

  -----------------------------------------------------------------------
  Тип                                 Описание
  ----------------------------------- -----------------------------------
  Pre-threaded plastic caps           Стандартная пластиковая винтовая
                                      крышка с готовой резьбой.

  Sport caps                          Спортивная крышка с поильником.

  Tethered caps                       Крышка, остающаяся прикрепленной к
                                      бутылке после открытия.

  Aluminum screw caps                 Алюминиевые винтовые крышки для
                                      стеклянных бутылок.

  Crown cork                          Кронен-пробка для стеклянных
                                      бутылок.
  -----------------------------------------------------------------------
